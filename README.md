
# Headers Checker

A beginner-friendly Python tool that checks whether a website sends five important security headers.

## What it checks
- Strict-Transport-Security
- Content-Security-Policy
- X-Frame-Options
- X-Content-Type-Options
- Referrer-Policy

## How to use
pip install requests
python checker.py https://example.com

## Notes
Built as a learning project with guidance from Claude (AI). Only use it on sites you own or public sites.
